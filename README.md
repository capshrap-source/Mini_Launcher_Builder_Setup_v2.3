# ⚡ Mini Launcher Builder by Shrapnel

### Create Your Own Custom Windows Launchers — v2.3

**100% FREE — Created by Captain Shrapnel**

Mini Launcher Builder is a standalone Windows application that allows you to create your own personalized mini launchers for almost anything!

Bring all your favourite games, websites, applications, music, movies, files and folders together in one convenient launcher.

No programming knowledge required. No separate Python installation required.

**Your shortcuts. Your design. Your launcher.**

## 🔥 MAIN FEATURES

### 🎨 Personalize Your Launcher

- Choose your own launcher name.
- Add a custom banner image.
- Select your own custom icon.
- Choose from the included spare icons.
- Create your own icons using the integrated online icon converter link.
- Preview your launcher before building.
- Stylish dark interface with neon colours.

### 🚀 Launch Almost Anything

- PC games

- Music and audio files
- Movies and videos
- Windows applications
- Documents and files
- Personal folders
- Gaming tools and utilities
- Online media platforms

### ⚙️ Built-In Launcher Builder

- Create standalone Windows EXE launchers.
- Integrated launcher engine.
- No separate Python or PyInstaller installation required.
- No coding experience needed.
- Choose where to save your finished launcher.
- Build launchers without an internet connection.

### 🛠️ Easy Shortcut Management

- Add custom shortcut buttons.
- Browse for files and folders.

## 📖 HOW TO USE

1. Open Mini Launcher Builder.
2. Enter your custom launcher name.
3. Choose an optional icon and banner.
4. Enter a button name.
5. Browse for a file or folder, or enter a website URL.
6. Click **Add to List**.
7. Repeat for all your favourite shortcuts.
8. Preview your custom launcher.
9. Click **BUILD MY CUSTOM EXE**.
10. Choose where to save your finished launcher.

Your personalized mini launcher is ready to use!
